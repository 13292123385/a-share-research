# A股免费收盘采集（第一版）

手机GPT免登录读取：[最新行情报告](https://raw.githubusercontent.com/13292123385/a-share-market-data/main/latest.md) · [公开行情首页](https://github.com/13292123385/a-share-market-data) · [JSON摘要](https://raw.githubusercontent.com/13292123385/a-share-market-data/main/latest.json)。先核对交易日和缺失状态。原仓库保持私有，公开入口只发布筛选后的行情数据。自动补采、发布及本机备用说明见 [PUBLIC_ACCESS.md](PUBLIC_ACCESS.md)。

Python 3.11+、AKShare、GitHub Actions；无数据库、付费 API 或常驻服务器。仅供数据研究。所有采集异常保留，不把异常、空表或缺失解释成“0只涨停”。

## 本地运行

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m collector.run
python -m collector.validate data
```

手动指定日期：`python -m collector.run --date 2026-10-23`。`--probe` 允许在日历无法确认时诊断接口，未确认的诊断数据不会进入有效每日快照。退出码0表示声明采集范围完整（可有单列的研究限制）或正常跳过；2表示必需采集失败、日历未知或诊断未验证。`collection_status`与`research_status`分别展示，不因历史实时快照不可恢复而伪装全量历史行情。历史股票池保留期限有限，不承诺长期回补。

### 采集质量改进

腾讯指数备用接口日期统一为 YYYYMMDD。主接口失败但备用成功时，失败尝试保存在 `sources.json` 与 `source_failures`，不再把已恢复的指数列为数据缺失。

同日后续采集复用已选归档中校验日期和OHLC通过的不复权候选日线，继续补剩余股票；不会复用其他日期价格。复用记录在价格表标记 `reused_from_prior_run`。

实时全市场主源失败时，尝试新浪行情。新浪分页全市场单独采用120秒硬超时及一次重试；官方名单最多三次尝试，各次失败分别留档。实测响应也含北交所，因此保留沪深北A股候选代码，并以官方名单逐只核对覆盖范围；不再预先丢弃北交所。周末诊断快照不能冒充交易日收盘。

中证2000在东方财富主源及重试失败后，使用中证指数官网 `stock_zh_index_hist_csindex(symbol='932000')`。逐行核对指数代码、日期和正数收盘价；仅使用已核对收盘字段，不假设其他字段/金额单位适用。

当日有效采集增加 `clean/market_reconciliation.json`：上海主板A股、科创板、深圳A股、北交所四份官方名单逐只连接，列出漏采、多出、重复代码；名单失败不当作空名单。不用当前名单验证历史日期。若已有行情仅缺少量沪深证券，最多对5只先补采腾讯直接报价，核对证券代码、目标日期及15:00后的时间戳；金额万元换算为元，成交量单位未核实则保留null。直接报价失败再补采同日腾讯不复权日线，标记来源及日期。日线无除权参考价时，涨跌幅保留null，不用前一日收盘猜涨跌方向；市场统计单列 `unknown_direction/unknown_amount`，有未知项时明确保留缺失。清洗后的实际汇总行情保存为 `clean/market_quotes.*`。

深圳成交额以官方主板A股+创业板A股之和，比较相同代码范围的快照金额，排除B股。缺价格行、重复代码、缺成交额时不比较；相对差异0.5%为本项目暂定工程容差，不是交易所验收标准。官方返回表没有独立日期列，记录日期来自请求参数。`code_coverage_matched`只表示本次名单代码覆盖一致；即使成交额在容差内，`all_market_verified`仍为false，因为其余股票行情日期、收盘时点及沪北成交额尚未逐项独立验证。指标继续列为估算，不宣称全市场所有字段已审计。

新增 `clean/first_board_followup.*`：从前两个交易日已选涨停归档提取主板首板，记录首板后第1/2个交易日的同日不复权OHLC，保留原始观察资格。价格单独保存为 `clean/followup_prices.*`；`--followup-budget` 默认300秒，复用当天已采价格后补缺失。按交易日而非自然日计算，缺少上一日归档时不向更早日期挪动；没有归档或价格则保留缺失。观察包含不合格与未知样本供核查，研究筛选应读取 `original_eligible_observation`。不推断买入，也不计算真实收益。

Actions新增数据完整性摘要，直接展示本次运行的缺失项目、指数覆盖、价格覆盖和失败类型；采集未生成摘要时提示缺失，不把旧归档冒充本次结果。指数返回日期错误、重复行、无效收盘价时同样触发重试和备用源。

当主板涨停股缺少当日 OHLC 时，按首板优先、代码排序，从腾讯补采目标日不复权日线，保存至 `clean/candidate_prices.*`。默认补采总预算420秒，单次最多15秒，`--price-budget 0` 可关闭。逐股核对日期唯一性及价格大小关系；预算耗尽、接口失败、日期错误仍标缺失，不视为非一字板。原始表保留成交量/额，清洗表也保留接口提供的 volume/amount；缺失不补零。此补采覆盖当天涨停股；前两交易日首板另由followup_prices跟踪，均不等于成交验证。

每日选用快照按已覆盖指数、价格、股票池和市场统计进行比较，新快照不丢失旧快照覆盖项时才更新 `latest.json`；完整快照不被部分结果替换。每日 `report.md` 仍展示最后一次尝试的情况，分析应以 `latest.json` 指向的运行报告为准。失败日志直接打印异常类别，不输出潜在凭据。历史补采以股票池、候选OHLC和四指数为必需范围；完整时返回0并标complete_with_limitations，仍明确列出不可恢复的历史实时市场及前序归档缺失；必需项失败返回2。

## 自动运行

将代码放在仓库默认分支，开启 Actions，并允许工作流读写 Contents。工作流使用 GitHub 内置 `GITHUB_TOKEN`，无需个人令牌；分支保护可能阻止数据提交，此时查看 Actions artifact。`workflow_dispatch` 可手工指定日期。输入通过环境变量传递，避免拼接 shell 表达式。

UTC cron `5,20,40 7 * * 1-5` 对应北京时间工作日15:05、15:20、15:40。先获取新浪交易日历，确认日历覆盖目标日期；非交易日正常跳过，日历过期/异常停止有效采集。仅在收盘后采集，延迟跨日不回猜调度原日期，可手动指定补采。

[GitHub 官方调度说明](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)：定时任务只在默认分支运行，可能延迟或被丢弃；公开仓库长期无活动可能停用定时任务。本方案是尽力采集，不能保证15:05准时开始。失败在保存证据后标红，后续两个时点继续尝试。串行调用、每次接口调用间隔至少2秒、每次45秒硬超时；指数最多一次重试及一次免费备用源，作业上限35分钟（固定ubuntu-24.04）。

优先公开仓库的标准托管 runner 免费方案；私有仓库受账户分钟数/存储额度限制。artifact保留7天，每次记录同时提交仓库便于长期追溯；没有可用额度时不会自动购买。长期运行需自行关注仓库数据大小，当前每天最多3组完整快照，未引入额外服务。

## 数据与来源

[AKShare 官方文档](https://akshare.akfamily.xyz/data/stock/stock.html)。依赖固定到实际测试的1.18.94，升级应先重跑验证。

| 数据 | 接口 / 来源 | 限制 |
|---|---|---|
| 交易日历 | `tool_trade_date_hist_sina` / 新浪 | 必须覆盖目标日期，不能仅按工作日判断 |
| 今日涨停 | `stock_zt_pool_em` / 东方财富 | 返回空表仍标待核验 |
| 昨日涨停今日表现 | `stock_zt_pool_previous_em` / 东方财富 | 不等于昨日首板名单，不提供昨日连板高度 |
| 炸板/跌停 | `stock_zt_pool_zbgc_em` / `stock_zt_pool_dtgc_em` | 历史窗口受上游限制 |
| 指数日线 | `stock_zh_index_daily_em` / 东方财富 | 日期严格匹配，收盘字段有效；失败重试 |
| 指数备用 | `stock_zh_index_daily_tx` / 腾讯 | 仅沪深指数；不假设腾讯支持中证2000 |
| 市场行情 | `stock_zh_a_spot_em` / 东方财富 | 仅采集当日收盘后；跨日历史留缺失 |

指数：上证 sh000001、深证成指 sz399001、创业板 sz399006、中证2000 csi932000。全市场上涨/下跌/平盘家数、成交额（元）由含沪深北的行情表汇总，标记为**估算值**：分页完整性、数据日期缺乏独立交叉确认，平盘可能包含停牌。它不是已核对交易所口径的市场总量。

原始股票池始终全量保留；清洗池严格限600/601/603/605、000/001/002/003六位代码，排除名称含ST（含*ST）、退字的证券，排除科创、创业和北交所。保存连板高度、首次/最后封板、开板次数与所属行业；缺少的字段逐行列于 `missing_fields`。行业不冒充概念题材；概念映射暂未采集。

全天一字板仅在**今日涨停池 + 同日OHLC齐全且开高低收相等**时标记排除；其余标为非一字或未知。历史采集不会拿当日实时行情补旧日期。T字、短暂开板仅作为观察样本，不能保证成交；缺少盘口排队、封单及实际成交验证。

## 一进二口径

今日首板候选池：今日清洗涨停池中连板数=1，附一字板状态，研究时仅取 `eligible_observation=true`。一字板及状态未知均不进入观察分母。

昨日首板今日晋级：只使用**上一交易日已归档**的清洗涨停池，取昨日连板数=1，与今日连板数=2及今日炸板池按代码连接。缺少昨天数据时整项为缺失，不使用昨日涨停接口冒充首板名单，也不按自然日找昨天。

观察分母为昨日非一字首板，剔除今日已知一字/未知状态的涨停股；观察晋级率=分母中今日二板数/分母。未晋级股票中，今日炸板池标记收盘炸板；收盘仍涨停但曾开板，可查看今日涨停的 `open_count`。这些是公开收盘池观察结果，不是可成交保证。

`verified_tradable_rate`、二板实际买价、第三交易日收益和最大不利波动保持null，直到有实际成交证据和完整行情。**可交易样本的一进二晋级率目前缺失**；不得将观察晋级率标为真实策略胜率。未来可定义第三日收盘/已验证买价−1、第三日最低/买价−1；本版只预留字段，不编造收益。第三日指首板后的第二个交易日。

## 题材15分三问

`industrial_space`产业空间0–5、`catalyst_persistence`催化持续性0–5、`market_recognition`市场认可0–5、`freshness`新鲜度−1/0/+1，最终限制0–15；任何一项未填则总分null。另有证据列表与人工复核人字段。主观项全部留空，本版不自动生成题材结论。

## 文件与质量

```text
data/YYYY-MM-DD/
  report.md                     # 最新一次尝试的中文报告，含失败/缺失
  latest.json                   # 有效日的最佳已选快照；可标partial
  runs/<北京时间唯一运行编号>/
    raw/*.json,*.csv            # AKShare返回的原始表，非HTTP原始响应
    clean/*.json,*.csv          # 主板池、首板、指数、晋级
    files.json,files.md        # 逐文件记录数、缺失字段、来源引用与字节校验和
    sources.json               # 来源接口、参数、抓取时间、状态、SHA256
    summary.json               # 交易日、完整性、已验证/估算/缺失、题材结构
    report.md                  # 本次不可覆盖的中文报告
```

JSON使用null，不写NaN；CSV的嵌套字段用JSON字符串。SHA256基于原始表JSON。每次尝试均独立归档，不以失败覆盖已选完整快照。空池标 `empty_unverified`，重复代码或必需列缺失标 `schema_error`；日期不符的指数不能纳入报告。上一日有效涨停池可用于后续联表，即使其市场快照等其他数据缺失。首次运行及历史回补的一字板/OHLC未知会阻止产生可比较观察样本，这是有意的缺失保护。

`unittest`覆盖股票范围、一字/T字、主观评分边界、缺失不能为0、晋级分母。离线 `collector.validate`检查日期目录、文件清单校验和、CSV/JSON记录数一致性、清洗范围与未验证收益字段；空目录报错；结构校验通过不代表上游数据齐全。网络实测见 [VALIDATION.md](VALIDATION.md)。无需任何密钥；不归档环境变量或带潜在凭据的完整网络异常。

当前修复与逐文件实测清单见 [REPAIR_2026-10-26.md](REPAIR_2026-10-26.md)。
